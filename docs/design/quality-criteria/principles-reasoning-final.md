
## Objective

Several [theories and research fields](../quality-criteria/principles-reasoning-argumentation-by-field.md) establish the principles of validity, reasoning, explanations, understanding versus logical validity. The current classification moves from a **field-by-field inventory** to a **cross-domain taxonomy**.

### Cross-fields synthesis

| Cluster                                          | Functional questions                                                                                                                                                                     | Normative objectives                                                                                                                                                                                                                                                                                                                        |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ─ _Inferential validity_ ─                       |                                                                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                             |
| **Formal and structural integrity of inference** | Logical architecture of arguments: locality of inferential steps, and formal correctness                                                                                                 |                                                                                                                                                                                                                                                                                                                                             |
| **Inferential relevance** (local)                | Does each element perform genuine inferential or explanatory work toward the conclusion?                                                                                                 | Each specific premise and inferential step must be genuinely used and pertinent.                                                                                                                                                                                                                                                            |
| **Economy** (global)                             | Are the elements collectively non-redundant? Is there no unnecessary complexity?                                                                                                         | The route must be direct rather than creating a needless detours.                                                                                                                                                                                                                                                                           |
| **Robustness**                                   | Have major objections, challenges or defeaters been treated? Is the reasoning resilient?                                                                                                 | Arguments must be stable under interactive scrutiny.                                                                                                                                                                                                                                                                                        |
| **Justification strength and calibration**       | Have claims been evaluated for strength, independence, stability? Are confidence levels proportional to support? ==TODO: what is strenght? what is stability (to what?)==                | The epistemic force must be actually measured. Confidence attached to conclusions must be _proportional_ to the strength and independence of the support. | ─ _Explanatory adequacy_ ─                       |                                                                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                             |
| **Necessity**                                    |                                                                                                                                                                                          | The argument must succeed _because of_ the essential properties of the objects and relations involved, not accidentally.                                                                                                                                                                                                                    |
| **Explanatory power and depth**                  | Does the reasoning reveal what generates, determines, or differentiates the result?                                                                                                      | The argument must reveals *why* a conclusion holds necessarily. Subtypes: cause/mechanism, structure/nomology, symmetry/invariance.                                                                                                                                                                                                         |
| Understanding                                    | Does the discourse answer why or how?                                                                                                                                                    | grasping modal, dependence, and structural relations                                                                                                                                                                                                                                                                                        |
| **Counterfactual sensitivity**                   | Does the argument isolate the factors that make the difference?                                                                                                                          | The argument must enable identification of _what would have to change_ for the conclusion to fail.                                                                                                                                                                                                                                          |
| **Systemic coherence and integration**           | Does the reasoning make make explicit a network of _dependence relations_?                                                                                                               | A reasoning should show what supports what, what explains what, what would change what.                                                                                                                                                                                                                                                     |
| **Unification**                                  |                                                                                                                                                                                          | A strong discourse explains many facts through a small number of principles.                                                                                                                                                                                                                                                                |
| ─ _Communicability_ ─                            |                                                                                                                                                                                          |                                                                                                                                                                                                                                                                                                                                             |
| **Transparency**                                 | Is each step locally interpretable, globally situated, and explicitly licensed — with no concealed inferential jumps?                                                                    | Every inferential step must be _individually scrutable_ and reconstructible without appeal to authority or tacit knowledge. The whole structure can also be inspected, tracked, and reconstructed.                                                                                                                                          |
| **Tractability**                                 | Is discourse structured for reconstruction, navigation, and step-by-step intelligibility?                                                                                                |                                                                                                                                                                                                                                                                                                                                             |
| **Manipulation**                                 |                                                                                                                                                                                          | Understanding is deeper when the structure can be perturbed                                                                                                                                                                                                                                                                                 |
| **Transferability**                              | Does the argument yield a reusable schema? Can the same pattern be recognized in nearby cases?                                                                                           | The argument must support manipulation, variation, reuse, and extension. The reasoning is stronger when it generalizes across contexts.                                                                                                                                                                                                     |
| **Progressive construction**                     | Is the presentation sequenced and framed so that inferential and explanatory structure becomes cognitively available? Are prerequisites activated? Are difficult transitions scaffolded? | Exposition must interface with the structural constraints of human cognition: sequencing, scaffolding, chunking, progressive disclosure.                                                                                                                                                                                                    |
| **Illustration** / **Pedagogical exposition**    | Are examples used to expose structure? Are analogies used?                                                                                                                               | Analogical mapping                                                                                                                                                                                                                                                                                                                          |
| **Constructive guidance**                        |                                                                                                                                                                                          | A reasoning must reveal the _strategy_ that leads to the result, not only the result once found.                                                                                                                                                                                                                                            |
|                                                  | Are likely misconceptions anticipated?                                                                                                                                                   |                                                                                                                                                                                                                                                                                                                                             |

## Practical evaluation framework

| Dimension           | Operational questions                                                                              |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| Robustness          | - Are the premises legitimate?  <br>- Is each inferential step warranted?                          |
| Global organization | - Is there a visible backbone?                                                                     |
| Tractability        | - Can the argument be mentally reconstructed?  <br>- Does it build a manipulable internal model?   |

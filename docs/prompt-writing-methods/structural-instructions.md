# AI prompt - structural instructions

Explicitly define the **organization of explanations**.

A structured format improves consistency and pedagogical clarity.

**Rationale**: Structure reduces the probability of missing key elements such as definitions or proofs.

**Example template**

For each concept:

1. Motivation
2. Informal intuition
3. Formal definition
4. Main theorem(s)
5. Proof sketch
6. Complete proof
7. Worked examples
8. Common pitfalls

# AI prompt - iterative interaction rules

For complex tasks, the prompt may define **interaction protocols**.

Examples:

- request clarification when ambiguity arises
- verify assumptions before proceeding
- progressively increase complexity

**Example**

```
Interaction rule:
If a concept requires prior knowledge not yet introduced,
pause and provide the prerequisite explanation first.
```

# AI Prompt - Style and Tone

Explicit style instructions significantly affect output quality. - Discourse register (formal, technical, scholarly)

Common parameters include:

- tone (formal, conversational, academic)  
- mathematical notation  
- use of examples  
- level of verbosity  
- Specific connective patterns required or prohibited (e.g., "use logical discourse connectors: _it follows that_, _consequently_, _by contrast_, _more precisely_; never use enumeration as a substitute for argumentative prose")

*Example*:

```
Style:
- Formal academic tone
- Avoid personal pronouns
- Use precise mathematical terminology
- Introduce formulas only after explaining their meaning
```

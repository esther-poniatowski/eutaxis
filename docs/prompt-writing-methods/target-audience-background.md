# AI Prompt - Target Audience and Background

Precise prompts specify **the knowledge level of the reader**.

**Rationale**: Without this constraint, responses often oscillate between overly simple and excessively technical.

Possible levels include:

|Level|Characteristics|
|---|---|
|Beginner|Requires intuition and examples|
|Advanced student|Familiar with fundamentals|
|Researcher|Expects rigor and abstraction|

*Example*:

```
Audience:
Assume strong background in calculus, linear algebra, and probability,
but no prior exposure to optimal control theory.
```

**Provide background and context**. Relevant contextual information helps the agent tailor responses.

Examples:

- research context
- specific application
- preferred frameworks

*Example*:

```
Context:
The material will be used to study mean-field games and collective behavior models.
Emphasize links between optimal control and Hamilton–Jacobi equations.
```

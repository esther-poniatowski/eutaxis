# Configuration

The `generate` command reads a YAML file that declares shared sources, per-agent
sources, and output targets. All file paths in the config resolve relative to
the config file's parent directory.

Default config file name: `agent-instructions.yaml`.

## Top-Level Keys

```yaml
common_sources:   # list of source entries shared across all agents
agents:           # list of agent definitions
```

Both keys are optional. An empty `common_sources` list (or omitted key) means no
shared content. An empty `agents` list produces no output.

## Source Entries

Each entry in `common_sources` or an agent's `sources` list has the form:

```yaml
- path: <relative-path-to-markdown-file>
  sections:            # optional
    - "Heading text"
    - "Another heading"
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `path` | string | yes | Path to a markdown source file, relative to the config file's directory. |
| `sections` | list of strings | no | Heading titles to extract. When omitted, the full file content is included. |

When `sections` is present, the generator extracts only the content under
headings whose text matches exactly. Each extracted block runs from its heading
to the next heading at the same or higher level. YAML frontmatter (`---` fences
at the top of a file) is stripped before extraction.

Missing source files produce a warning but do not abort generation.

## Agent Definitions

Each entry in `agents` has the following structure:

```yaml
- name: claude
  enabled: true
  target:
    path: .claude/CLAUDE.md
    header: |
      # CLAUDE.md
      Agent instructions (auto-generated).
    footer: |
      ---
      *Auto-generated by eutaxis.*
  sources:
    - path: docs/instructions/claude-specific.md
```

### Agent Fields

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `name` | string | yes | -- | Identifier for the agent (used in log output). |
| `enabled` | bool | no | `true` | Set to `false` to skip generation for this agent. |
| `target` | mapping | yes | -- | Output file configuration. |
| `sources` | list of source entries | no | `[]` | Agent-specific source files appended after common sources. |

### Target Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `path` | string | yes | Output file path, relative to the config file's directory. Parent directories are created automatically. |
| `header` | string | no | Text prepended before all source content. |
| `footer` | string | no | Text appended after all source content. |

## Assembly Order

The generator concatenates content for each agent in this order:

1. `target.header` (trimmed)
2. Each `common_sources` entry, in list order
3. Each agent-specific `sources` entry, in list order
4. `target.footer` (trimmed)

Parts are joined with double newlines. The output file ends with a single
trailing newline.

## Full Example

```yaml
common_sources:
  - path: docs/instructions/style-rules.md
    sections:
      - "Hard blockers"
  - path: docs/instructions/note-template.md

agents:
  - name: claude
    enabled: true
    target:
      path: .claude/CLAUDE.md
      header: |
        # CLAUDE.md
      footer: |
        ---
        *Auto-generated by eutaxis.*
    sources:
      - path: docs/instructions/claude-workflow.md

  - name: copilot
    enabled: false
    target:
      path: .github/copilot-instructions.md
    sources:
      - path: docs/instructions/copilot-workflow.md
```

Running `eutaxis generate -c agent-instructions.yaml` with this config writes
`.claude/CLAUDE.md` (the claude agent) and skips the disabled copilot agent.

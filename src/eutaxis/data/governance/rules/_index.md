# Decision Rules

Cross-referencing hub for all decision rules in the governance system.

Rules are organized by the aspect of note production they govern:

| Layer | Governs | Priority |
| --- | --- | --- |
| **Epistemic** | What is claimed | Highest |
| **Argumentative** | How the claim is articulated | Medium |
| **Stylistic** | How the result is expressed | Lowest |

Each rule file specifies a normative constraint and the checks by which
any workflow stage may verify compliance.
